# My Paycheck Plan v3

Adds fully customizable spending and saving categories with icons.

## Features
- Add unlimited categories
- Rename, delete, and reorder categories
- Choose an icon for every category
- Fixed amount or percentage allocation
- Separate categories and results for each saved month
- Monthly history, annual chart, dark mode, and currency formatting
- Automatic migration from the older Savings/Fuel/Going out settings

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Update Vercel
Replace the files in the existing connected GitHub repository and commit. Vercel will redeploy automatically.
